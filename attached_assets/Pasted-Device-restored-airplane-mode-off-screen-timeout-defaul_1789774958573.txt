## Root cause

**Application bootstrap issue, not packaging.** The auth-gating chain renders *no fallback UI*: `<ClerkLoaded>` (`_layout.tsx:98`) plus the `!isLoaded → return null` guards in `(tabs)/_layout.tsx:13` and `sign-in.tsx:64`. Offline, Clerk must still initialize/sync against `api.clerk.com`; that finishes only after a network-timeout/retry delay that's wildly variable (0.5s vs 17s observed). Until then the navigation tree is `null`, so the screen shows only the **empty window background — white `DayNight.NoActionBar` theme in light mode** (device is light-mode; splash `#111315` is dark but dismisses once fonts load). It is *recoverable*: once Clerk's cached session resolves, the local-first Today screen renders entirely from AsyncStorage with zero network. But during the gap the user sees a stuck-looking white screen.
