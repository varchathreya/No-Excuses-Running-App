## Marker lifecycle
- Set `"1"` only when `ApiAuthentication` observes `isLoaded && isSignedIn`.
- Set `"0"` when loaded-and-signed-out (any sign-in screen) and immediately on sign-out confirm.
- Read only by `AuthBootstrap`; granted access is in-memory and revoked the moment Clerk loads.

## State flow
Fresh install → offline: loading 10 s → branded "No saved session found" (no entry). Prior sign-in → offline boot: loading 10 s → app tree mounts, tabs accessible (AppContext hydrates from storage; calendar preview/quote/API stay off via `networkAvailable`; no bearer token). Offline sign-out: marker cleared + revoked → redirect to `/sign-in` locked screen. Server session revoked later: next online boot Clerk loads unsigned → marker `"0"`, form shows. Network returning after grant: Clerk loads → revokes grant, guards defer to Clerk.
