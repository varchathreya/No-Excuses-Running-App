---
name: Android delivery
description: Platform constraint for testing and publishing Expo mobile apps from this workspace
---

Use Expo Go with the QR code from the running mobile preview for immediate Android testing. The workspace's Expo Launch flow is for iOS App Store submission; it does not publish Android apps to Google Play.

**Why:** The user is working from Windows 10 and needs an Android test path first, so the handoff must distinguish device testing from store publishing.

**How to apply:** Give Windows users QR/Expo Go instructions first, then explain that Google Play release requires an Android-capable build/submission path outside Expo Launch.
